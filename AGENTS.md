# Project workflow

For every task in this project:

1. Read `memory/project.md`, `memory/project_state.md`, `memory/decisions.md`, `memory/todo.md`, `memory/user_preferences.md`, and `memory/known_issues.md` before inspecting historical conversation.
2. Inspect only the current project files needed for the task.
3. Implement and validate the requested work.
4. Update the relevant memory files whenever a decision, state, completed feature, removed feature, fixed bug, known issue, or priority changes.
5. Keep memory concise and authoritative: replace outdated conclusions instead of preserving conflicting history.

Use conversation as temporary context only. Consult older conversation only when memory and current files are insufficient.
